## DeckRoulette with Sort — 1.3.27-sort.6

### Removed
- **The temporary Recently Opened Diagnostics section** under Customize Shortcuts → Shortcuts. It was only there to confirm that collection visits were being detected, and they are. The plugin also no longer keeps its log of recent Steam pages.

### Recently Opened, as it works now
A list counts as "opened" when you pick it with the roulette button, switch to its Library tab (including Tab Master tabs with the same name as a collection), visit its collection page, or play a game from it. Whichever happened last decides the order.

### Docs
- The README now has screenshots of the **Sort** button in **Browse Other Lists…** and in **Customize Shortcuts → Available Shortcuts**.

### Notes
- Pinned shortcuts keep the order you set by hand. Unpin a list in Customize Shortcuts if you want it included in the sorted lists.
- Your saved sort mode and history carry over unchanged.
