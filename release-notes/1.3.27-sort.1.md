## DeckRoulette with Sort — 1.3.27-sort.1

Fork of [chrisae9/deck-roulette](https://github.com/chrisae9/deck-roulette), now fully synced with the parent's v1.3.27 and with sorting added.

### New
- **🔀 Sort button** in **Browse Other Lists…** and in **Customize Shortcuts → Available Shortcuts**.
  - **Alphabetical** (default), **Recently Rouletted**, **Recently Opened**.
  - *Locally Installed Games* and *My Games* stay at the top; ties fall back to A–Z.
  - Your choice and roulette history are remembered between sessions.

### Updated
- Merged all 35 new commits from the parent: pinned shortcuts, native reordering, collection exclusions, Browse Other Lists, Customize Shortcuts and more.

### Changed
- The old "Recently Created" mode is gone, because the parent now always lists collections alphabetically. Saved values fall back to Alphabetical.

### Install
Download `DeckRoulette-with-sort-1.3.27-sort.1.zip`, then in Decky: Settings → General → Developer Mode → Developer → **Install Plugin from ZIP**. Remove any other DeckRoulette install first.
