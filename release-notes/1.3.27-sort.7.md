## DeckRoulette with Sort — 1.3.27-sort.7

### Cross-platform
- The plugin is verified to install from the same zip on a **Steam Deck** (Decky → Install Plugin from ZIP) and on **Windows** (unzip into `homebrew\plugins`). No plugin code changed.
- Added a `.gitattributes` so every text file stays **LF** when the repository is cloned on Windows. Previously a Windows clone turned every file into CRLF, which made Git show all files as modified and could put CRLF files into a locally built zip.

### Docs
- The README now explains how to install the one zip on Steam Deck and on Windows.

### Notes
- Your saved sort mode and history carry over unchanged.
