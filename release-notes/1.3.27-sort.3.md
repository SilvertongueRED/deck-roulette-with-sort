## DeckRoulette with Sort — 1.3.27-sort.3

### Fixed
- **Recently Opened now looks in more places for the collection you open.** In 1.3.27-sort.2 the plugin only checked the browser address, which Steam's Game Mode UI may not update when you move between pages. It now also reads Steam's own page history, and accepts more route shapes.

### Added
- **Recently Opened Diagnostics** at the bottom of **Customize Shortcuts → Shortcuts**. It shows how many collection visits have been recorded and the last pages Steam reported. If Recently Opened still does not move a collection to the top, this readout shows what Steam is actually reporting, so the tracker can be pointed at the right place.

### Notes
- Open a collection in your Library, then check **Browse Other Lists…** with **Current: Recently Opened** selected.
- The diagnostics section is temporary and will be removed once collection visits are confirmed working.
