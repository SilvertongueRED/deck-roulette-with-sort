## DeckRoulette with Sort — 1.3.27-sort.5

### Added
- **Tab Master tabs now count as opening a collection.** Switching to a Library tab (including ones made by Tab Master) whose name matches one of your collections, such as Favorites, Cozy or Horror, moves that collection to the top of **Recently Opened**. These tabs do not change Steam's page address, so the plugin now reads which tab is highlighted.

### Notes
- Matching is by name, ignoring upper/lower case. A tab with no collection of the same name (for example a Tab Master filter tab such as Demo) is ignored.
- The tab that is already showing when Steam starts is not counted as a visit. Switching tabs, or coming back to the Library, is.
- The diagnostics readout (Customize Shortcuts → Shortcuts) now also lists the tab names it sees, under `library-tab`.
